MARCELA & MIGUEL — WEDDING WEBSITE V1

FILES
- index.html — website structure/content
- style.css — design/responsive layout
- script.js — bilingual switch, countdown, animations, RSVP preview

PENDING FOR V2
- Reception venue and time
- RSVP deadline
- Couple story
- Couple photos / hero photo
- Live RSVP storage endpoint (Google Forms/Formspree/etc.)
- Music audio: "Hasta Mi Final" by Il Divo is NOT bundled. Use only an audio file/embedding method you are authorised to publish.

GITHUB PAGES
1. Create a GitHub repository (example: marcela-miguel-wedding).
2. Upload index.html, style.css and script.js to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment choose Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. GitHub will display the public Pages URL after deployment.

RSVP
The current form is a visual/interactive demo and intentionally does not store personal data. Connect it to your preferred form service before sharing publicly.
